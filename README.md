# Pokédex — React + Next.js

Aplicación web que consume la PokéAPI para mostrar el listado completo de los 151 pokémon originales, con buscador y sistema de favoritos.

---

## 🔗 Demo en vivo

[Ver aplicación en Vercel](https://next-pokemon-project-1h4bu05x2-sebagiordano.vercel.app)

## 🛠️ Tecnologías utilizadas

`React` `Next.js` `JavaScript` `CSS` `PokéAPI` `Vercel`

## ✨ Funcionalidades

- Listado completo de los 151 pokémon originales
- Buscador por nombre en tiempo real
- Sistema de favoritos persistente
- Página de detalle por pokémon
- Deploy automático en Vercel

## 📚 Lo que aprendí

- Consumo de APIs REST externas con Next.js
- Manejo de estado con React Hooks
- Deploy y hosting en Vercel
- Optimización de imágenes con Next.js Image
